# 数据管理计划（对应论文附录 B、§6.10）

## 数据类别与去向

| 类别 | 去标识化 | 发布方式 |
|---|---|---|
| 问卷汇总统计、分析脚本 | — | 本仓库直接公开 |
| 个体级去标识问卷数据 | 化名编号（P1–P12），移除可识别信息 | 申请制访问（签署数据使用协议） |
| 访谈录音 | 转录校对后仅保留文本 | 不发布 |
| 访谈转录与编码 | 化名编号；引文经被试单独授权后引用 | 编码手册与全部编码随本仓库 supplementary/ 公开；转录申请制 |
| 操作日志（z、操作、时间戳、奖励） | 化名编号 | 汇总结果随论文表7；个体级申请制 |
| 训练数据音频 | — | 不分发；仅元数据与提取脚本 |
| 奖励评分数据（8 位制作人 ×120 条） | 各自均值-标准差标准化 | 汇总口径随论文 §4.3 |

## 撤回机制

- 被试与奖励评分者均可随时联系 akiromusic@qq.com 撤回数据（数据发表前）。
- 奖励评分者另行签署数据使用同意书。
- 训练数据涉及艺术家设公开 opt-out 通道，申请即从训练集及后续重训版本移除。

## 保存与保留

- 知情同意书纸质件存档备查。
- 随机种子集中登记于仓库 `seeds.yaml`（模型训练 / UMAP / Bootstrap / 任务顺序），
  保证结果逐次可复现。
- 分析口径：全文数字以论文表7（结果总表）为唯一口径，由 `analysis/reanalysis.py`
  从原始数据模板重算。
