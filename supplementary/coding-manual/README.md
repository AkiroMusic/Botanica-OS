# 质性编码手册（对应论文 §6.5、附录 C）

## 编码流程

1. 访谈录音经被试授权，Whisper large-v3 转录，人工对照录音复核专名与术语。
2. 转录逐句**开放编码** → **轴心归类** → **主题归纳**。
3. 编码者：作者本人。方法局限（论文 §6.5 声明）：编码者参与系统设计，存在确认偏差
   风险；未引入第二编码者计算 Cohen's κ，未做成员检查（member checking）。
   读者对主题覆盖面的解读应留有余量。

## 主题定义（T1–T4）

### T1 · 示能性迁移（11/12 被试提及）

被试报告三范式逐渐改变了他们对潜在空间的感知方式——从抽象坐标转向可操作的
隐喻空间。

> 示例：「开始我把 UMAP 图当作一个抽象坐标，做了 20 分钟 Graft 后我开始把它想象
> 成两个父本之间的果园」（P3）

编码规则：涉及「对空间/操作的理解方式发生变化」的陈述归入本主题；
单纯的操作偏好陈述不归入。

### T2 · 能动性悖论（8/12 被试）

被试在 Cultivate 模式下报告可控性下降但能动性上升：不确定下一步会出现什么，
但感到是「自己」在引导。

> 示例：「我不知道下一步会出现什么，但感觉是『我』在引导它」（P9）

编码规则：同时包含「不可预测/失控」与「引导感/所有权」两个成分的陈述归入；
仅抱怨失控、无引导感的不归入。

### T3 · 美学漂移（9/12 被试）

长期 Cultivate 任务中，音色的美学方向随轨迹演化而漂移，且被试对意外结果
报告满意。

> 示例：「我以为我在找一个湿润的 Pad，结果 20 步后变成了某种骨头敲击声，
> 但这个意外让我满意」（P1）

编码规则：包含「目标偏移/意外结果」且「对该意外持接受或积极评价」归入；
仅报告不满意的偏移归入失败案例记录（论文 §8.2），不归入本主题。

### T4 · 算法权威感知（6/12 被试，主要为 ML 研究者）

被试对系统通过奖励函数或条件后验「建议」美学方向表达警惕或反思。

> 示例：「我担心系统在用奖励函数告诉我什么是好音色」（P10）

编码规则：涉及「算法在替我做判断/我在让渡判断」的陈述归入；
一般性功能抱怨（如条件失真，见 P11 案例）不归入。

## 子组说明

论文 §6.6：T4 在 ML 研究者子组的提及率更高（5/6 vs 制作人子组 1/6），
子组比较为探索性（N=6/组，未校正）。

## 反面案例的收录

失败案例（论文 §8.2）单独记录，不与 T1–T4 混编：P5 主动退出
（「算法在偷我的判断」）、P11 在 Graft 下未找到满意音色、Hybridize 的
OOD 条件失真（「火焰般湿润」）。
