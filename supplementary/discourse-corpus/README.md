# Botanica 社区话语分析语料（对应论文 §3.7）

## 语料选择标准（论文原口径）

- 来源：Bandcamp 风格标签含「Botanica」的专辑及其 liner notes，辅以 Bandcamp Daily 相关文章
- 发行时间：2020–2024
- 排除：现场录音合集
- 规模：20 张专辑，语料约 15,000 英文词

## 分析方法（论文 §3.7 声明的口径）

由作者**人工**完成关键词聚类计数：词形归并后归入先验设定的四个隐喻簇，
统计各簇占比。未使用自动化分词或主题模型软件。

| 隐喻簇 | 示例词 | 占比 |
|---|---|---|
| 生长/演化 | grow, evolve, develop, morph | 32% |
| 生态/共生 | symbiotic, mycorrhizal, eco, organic | 24% |
| 手工/培育 | cultivate, nurture, tend, graft | 18% |
| 常规描述 | — | 26% |

方法局限（论文声明）：单一分析者，未做第二编码者信度检验（如 Cohen's κ），
聚类边界含判断成分，定位为「初步话语分析」，为三范式命名提供动机性证据。

## 文件

- `albums_schema.csv`：20 张专辑清单的**字段结构**。完整清单（专辑名、艺术家、
  年份、风格标签、链接）将由作者核验后提交至本目录——清单涉及第三方作品信息，
  需逐条核对后再公开，当前为占位。
