# 目标音色簇（对应论文 §6.3）

用户研究中的三范式任务均以预实验确立的 **8 个音色簇** 为目标音色。每个簇是三个
感知维度的原型组合：

- **颗粒密度**（grain density）：颗粒时间尺度 1–100 ms 的密度起伏（论文 §2.4：
  颗粒时间尺度是 Botanica 音色指纹的关键频带）
- **谐波稳定性**（harmonic stability）：频谱峰值的漂移程度（稳定 ↔ 漂移）
- **湿润度**（wetness）：社区隐喻语言中的「湿润」维度（§3.7 生态/共生隐喻簇）

## 文件

- `clusters_schema.csv`：字段结构。8 个簇的定义与参考音频清单将由作者随代码发布
  逐项填入——参考音频涉及版权作品，仅公开清单与获取方式，不随仓库分发音频。

## 复用说明

新研究可按「三感知维度 × 原型组合」的逻辑自建目标音色集，并在论文中报告维度定义
与选择程序；目标音色定义的变化属于研究设计变更，需在结果可比性声明中说明。
